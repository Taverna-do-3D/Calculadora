☁️ Sincronização Nuvem (Supabase)

Conecte sua conta do Supabase para ter backup automático e sincronizar pedidos entre o PC e o celular em tempo real.

📋 Passo a Passo para Configurar o Supabase

1. Crie seu projeto grátis: Acesse supabase.com e crie um projeto.

2. Pegue a URL e a Chave: No menu lateral esquerdo do Supabase, vá em Project Settings (ícone engrenagem) ➔ API. Copie a Project URL e a anon public key e cole nos campos acima.

3. Crie a Tabela de Dados: Vá em SQL Editor ➔ New Query no Supabase, cole o código abaixo e clique em Run:

create table if not exists public.taverna_state (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null default '{}'::jsonb,
  updated_at timestamp with time zone default timezone('utc'::text, now()) not null
);

alter table public.taverna_state enable row level security;

create policy "Users can manage their own state"
  on public.taverna_state for all
  using (auth.uid() = user_id)
  with check (auth.uid() = user_id);

4. Pronto! Digite seu e-mail e senha nos campos acima e clique em Criar Conta (ou Entrar). Seus dados serão sincronizados automaticamente sempre que você fizer alterações!
