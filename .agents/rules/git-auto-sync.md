# Auto Git Sync Rule

Sempre que forem feitas alterações ou melhorias no código/projeto da Calculadora:
1. Realize os testes e verificações necessárias.
2. Adicione os arquivos modificados ao Git (`git add .`).
3. Crie um commit descritivo em português ou Conventional Commits.
4. Envie as alterações automaticamente para o repositório remoto via `git push origin main`.
